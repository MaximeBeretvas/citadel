# Citadel: Logo Guidelines

## 1. The logo
- **Idea:** a lens frames a walled skyline under a rising beacon. The lens stands for search and query, the wall for the local, fortified store, and the beacon for docs kept fresh.
- **Versions:** horizontal lockup (primary) · stacked lockup · symbol only · wordmark only.
- **Wordmark:** custom geometric lowercase `citadel`, built as outlines. It uses the same ring construction as the symbol. It has no font licence, so never retype it in a font.

| Use | File |
|---|---|
| Primary, light backgrounds | `citadel-horizontal.svg` |
| Primary, dark backgrounds | `citadel-horizontal-reversed.svg` |
| Stacked (square-ish spaces) | `citadel-stacked.svg` · `citadel-stacked-reversed.svg` |
| Symbol, 40 px and up | `citadel-symbol.svg` · `citadel-symbol-reversed.svg` |
| Symbol, 32 px and below | `citadel-symbol-small.svg` · `citadel-symbol-small-reversed.svg` |
| Wordmark alone | `citadel-wordmark.svg` · `citadel-wordmark-reversed.svg` |
| App icon | `citadel-app-icon.svg` (rounded) · `citadel-app-icon-fullbleed.svg` (iOS / maskable) |
| One colour | `variants/*-black.svg` · `*-white.svg` · `*-mono-2563eb.svg` |
| Web / PWA icons | `web/`: paste `web/head-snippet.html` into `<head>`, serve the files from the site root. `favicon.svg` switches to white with Beacon Light in dark mode; `favicon.ico` and the PNGs use `favicon-tile.svg` (Navy tile) so they read on any tab colour |

## 2. Clear space
Let **x** be the width of the ring. Keep **2x** of empty space on every side of any version. The zone scales with the logo, so never use a fixed pixel distance.

## 3. Minimum size
| Version | Screen | Print |
|---|---|---|
| Horizontal lockup | 96 px wide | 25 mm wide |
| Stacked lockup | 64 px wide | 18 mm wide |
| Symbol (master) | 40 px | 10 mm |
| Symbol (small-size cut) | 16 px | 5 mm |

Below 40 px, always switch to the small-size cut. It has a thicker ring, two battlements and a larger beacon, so the idea survives in a browser tab.

## 4. Colour
| Name | Role | HEX | RGB | CMYK (approx.) | Pantone (nearest, verify with a swatch book) |
|---|---|---|---|---|---|
| Citadel Navy | Ring, wall, wordmark; app-icon tile | `#0F172A` | 15 · 23 · 42 | 64 · 45 · 0 · 84 | 5395 C |
| Beacon Blue | Beacon on light backgrounds | `#2563EB` | 37 · 99 · 235 | 84 · 58 · 0 · 8 | 2728 C |
| Beacon Light | Beacon on dark backgrounds | `#60A5FA` | 96 · 165 · 250 | 62 · 34 · 0 · 2 | 284 C |
| White | Reversed ring, wall, wordmark | `#FFFFFF` | 255 · 255 · 255 | 0 · 0 · 0 · 0 | — |

**Contrast (WCAG):** Navy on white 17.9:1 · Beacon Blue on white 5.2:1 · Beacon Light on Navy 7.0:1. Beacon Blue on Navy is only 3.45:1, so on dark backgrounds always use the reversed files, which carry Beacon Light.

**Approved pairs:** full colour on white or light grey · reversed on Navy or any dark UI · white one-colour on Beacon Blue · black one-colour for single-ink print. On photos, use the one-colour white or black version over a calm area.

The Citadel UI accent is currently green (`--accent: #15803d` in `src/ui/assets/style.css`). Pair the logo with a Beacon Blue accent, or keep green and let the logo stand as the only blue element. Don't mix both blues and greens in the same component.

## 5. Typography
- **Logo:** the custom wordmark only, never typed.
- **Product UI and docs:** the existing system stack (`-apple-system, BlinkMacSystemFont, "IBM Plex Sans", "Segoe UI", sans-serif`). It's offline-friendly, which fits the zero-CDN rule.

## 6. Don'ts
Don't stretch, squash or rotate. Don't recolour outside the palette, and don't make the beacon any colour other than Beacon Blue or Beacon Light. Don't add shadows, outlines, gradients or glows. Don't fill the window behind the skyline. Don't rearrange or resize the parts of a lockup. Don't use the master symbol below 40 px. Don't place the logo on busy backgrounds without a container.

## 7. Notes
- **Trademark:** not cleared. Run a professional trademark search and a reverse image search before any public launch.
- **Masters:** this folder. The symbol, lockup, wordmark and app-icon SVGs are generated by `build.py` (`python3 build.py .`), so edit the geometry there and not by hand in each file. `citadel-app-icon-fullbleed.svg`, `variants/` and `web/` are derived from those files.
