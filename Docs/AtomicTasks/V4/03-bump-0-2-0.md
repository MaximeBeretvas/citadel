# Task V4-03: Bump to 0.2.0

- **Phase:** V4
- **Dependencies:** V4-04
- **Suggested Commit:** `chore(release): bump version to 0.2.0`

## Goal
Publish the `chrome`-by-default build as v0.2.0, the first GitHub release, so `citadel update`
can move an installed 0.1.0 to it.

## Exact Files
- `Cargo.toml` / `Cargo.lock`: `0.2.0`.
- `src/ui/assets/index.html`: fallback version pill `v0.2.0`.

## Acceptance Criteria
- `citadel --version` prints `citadel 0.2.0`.
- The `release.yml` tag guard accepts tag `v0.2.0`.
- After the release is published: `citadel update --check` on 0.1.0 reports 0.2.0, and
  `citadel update` replaces the binary and restarts a running daemon.
